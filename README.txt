SEBELUM DIUNGGAH
1. Ganti assets/images/profile.svg dengan foto diri yang pantas. Jika memakai foto JPG/PNG,
   ubah juga nilai src pada index.html, misalnya assets/images/foto-darwani.jpg.
2. Pada portofolio.html, ganti dua tautan https://drive.google.com/ dengan tautan publik
   hasil Tugas 1 dan Tugas 2 yang sebenarnya.
3. Periksa kembali isi dan identitas sebelum dipublikasikan.

UJI LOKAL
Buka index.html menggunakan browser. Pastikan ketiga halaman dan navigasi berfungsi.

DEPLOYMENT GITHUB PAGES
1. Buat repositori publik bernama tugas3-cloud-2353027123.
2. Unggah seluruh isi folder ini ke bagian utama/root repositori (index.html harus di root).
3. Buka Settings > Pages.
4. Pada Build and deployment, pilih Deploy from a branch.
5. Pilih branch main dan folder /(root), lalu Save.
6. Tunggu proses selesai. URL umumnya:
   https://USERNAME.github.io/tugas3-cloud-2353027123/
7. Buka URL publik melalui jendela privat untuk memeriksa akses.
